# Есть что приготовить

Одностраничное веб-приложение, которое предлагает три наиболее подходящих блюда из продуктов пользователя.

## Возможности

- ручное добавление продуктов с локальными автоподсказками и управлением с клавиатуры;
- справочник из более чем 150 распространённых продуктов;
- единый список продуктов в виде тегов без дублей;
- загрузка фотографии, локальный preview и подтверждение найденных продуктов;
- нормализация регистра, пробелов и популярных вариантов названий;
- подбор из 180 рецептов домашней кухни без внешних API;
- три уровня сложности и семь типов блюд;
- необязательный фильтр по кухне или стилю блюда;
- взвешенный рейтинг по совпадениям, недостающим и основным ингредиентам;
- разнообразие выдачи по способу приготовления, типу блюда и основным продуктам;
- первые три рекомендации и загрузка следующих вариантов порциями по шесть;
- список имеющихся и недостающих ингредиентов;
- адаптивный интерфейс для компьютеров, планшетов и телефонов;
- доступные состояния формы и поддержка уменьшенной анимации.

## Распознавание фотографий

Изображение обрабатывается локально в браузере и не загружается на сервер. Текущая безопасная MVP-версия анализирует преобладающие цветовые области и может осторожно предложить несколько визуально характерных продуктов. Результат всегда подтверждает пользователь.

Такой способ не заменяет полноценную модель компьютерного зрения и не сможет надёжно разобрать сложную фотографию холодильника или несколько похожих продуктов. Для качественного распознавания потребуется backend или serverless-функция, которая безопасно хранит ключ сервиса компьютерного зрения. Приватные ключи в публичном клиентском коде не используются.

## Запуск

Откройте `index.html` двойным щелчком в любом современном браузере. Установка зависимостей и интернет не требуются.

## Файлы

- `index.html` — структура страницы;
- `styles.css` — оформление и адаптивность;
- `products.js` — локальный справочник продуктов;
- `recipe-library.js` — расширенная база и структура рецептов;
- `script.js` — рецепты, подбор, подсказки и локальный анализ фотографии.

Каждый рецепт содержит поле `cuisine` — массив с одним или несколькими значениями: `european`, `asian`, `italian`, `central-asian`, `georgian`, `mediterranean`, `middle-eastern`, `home`, `healthy` или `quick`.
